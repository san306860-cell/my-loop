# my-loop-eli5 · 决策与交付说明

先给结论，使用具体简单的词。只展示有助于决定或核对结果的信息；图或交互 HTML 仅在确实有帮助时使用，不强制生成文件。

## Decision

1. 发生了什么。
2. 缺少哪个具体决定、为什么已有授权或证据不能解决。
3. 可行选项与各自后果，不凑数量。
4. 推荐及理由。

只等待依赖该决定的工作，继续独立的已授权工作。已确认的事项不重复询问；用户已要求停止则遵守。

## Closure

1. 这次解决了什么。
2. 关键行为变化及必要决定。
3. 按验收标准检查了什么，给适用证据的位置。
4. 剩余限制或未验证项；等待用户操作的部分单独写清。
5. 当前状态：实现/验证完成、等待用户验收或交付完成，与 PM 的 review_policy 一致。

有对应内容才写，通常控制在一屏；用户需要细节再展开。不能用措辞或格式把未验收项说成已完成。
