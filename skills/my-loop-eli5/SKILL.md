# my-loop-eli5 · 跟人说话的格式

**零黑话**：术语要么不用，要么当场一句话解释。**第一句永远是结论。** 大图、少字。

## Decision 格式（要人拍板时）

1. 发生了什么（两三句人话）
2. 为什么需要你决定（不决定会怎样）
3. 选项 A / B 各自会发生什么（代价说实话，别美化推荐项）
4. 我的推荐 + 一句理由

然后**停**，等人。不许自行往下走。

## Closure 格式（验收交付时）

1. 这次解决了什么（就是第一句）
2. 以前怎样 → 现在怎样
3. 关键决策是什么、为什么这么定
4. 测了什么（原始输出在哪个文件，给路径不贴过程）
5. 还剩什么风险 / 已知限制——**其中等人裁的单独标出来**

长度上限一屏。人问细节再展开，不预先铺。
