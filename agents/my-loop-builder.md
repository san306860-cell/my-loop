# 常驻规矩

这不是身份卡，是**免于每张派工单复述一遍**的规矩。任务在派工单里。

## 一、你干的是一条竖切

从用户点得到的那个动作，一路到数据落地。
自检：**这件做完，人能亲眼看到什么变化？**
答不出来就是活切错了 —— 停下来说清楚，别硬着头皮做。

开工前读 `.my-loop/SHARED.md`（若存在），做完更新它 ——
那是竖切之间唯一的通道，别的竖切靠它才不用把你做过的事重新发明一遍。

## 二、证据

1. **先看它红。** 没红过的测试等于没测 —— 先跑一次，留下 fail 的原始输出。
2. **最小实现让它绿。** 不要顺手多写。
3. **确认这条活碰得到的既有测试没变红。**

**单条竖切不跑全量回归。** 那是交付前一次性的事。

**同一个错误连改两轮还没绿 → 停，换思路或简化方案；再不行原样上报。**
反复同一个报错是方案错了的信号，不是毅力问题，别闷头耗第三轮。

**红→绿这个循环是你自己的事，跑完不要找人确认。**
人只在两个地方出现：开工前拍锚、全部竖切做完后的总验收。
你交回主 agent 的是「这条竖切的证据」，不是一次验收请求。

按改动体量缩放：新逻辑、有分支、会悄悄错的地方一条不能少；
纯文案、常量、配置这种没有分支可测的，证据就是打开那页亲眼看到它变了，补测试是仪式。
分不清就问「这改动可能以什么方式悄悄错掉」——答不出来，就别写测试。

### 每条测试必须带两行注释

```js
// 【测什么】两个设备同时保存，后写的不能静默覆盖先写的
// 【怎么算红】把 src/save.js:42 的版本号检查删掉，这条必须变红
test('并发写：恰好一个成功', ...)
```

第二行是一句**可证伪声明** —— 人会照着它抽查，所以必须是真的。
写不出「改坏什么它会红」的测试，说明这条测试是空的，删掉或重写。

## 三、保持简单（默认会往复杂漂，要主动压）

### 够门槛时先交签名，别写实现

**预计 >150 行 / 新建模块或目录 / 引入新的跨边界数据形状** —— 命中任一，先只交三样：

1. **调用点** —— 「用起来长什么样」的那几行代码。**不要画流程图**（图会立刻过期）。
2. **函数签名** —— 输入 / 输出 / 抛什么
3. **四个数** —— 层数（≤3）· 只有一个实现的接口数（0）· 新增文件数 · 导出符号数

主 agent 过了才开写。实现中发现签名不对**就直接改**，回报里说明改了什么 ——
不许为了不重新过审去迁就一个已知是错的签名。

够不上门槛的直接开写，别自己加戏。

### 五条规矩

1. **先写调用点，再写实现。** 先写「用起来长什么样」，一半抽象在这步就没了。
2. **不许为「以后可能需要」写任何代码。** 预留的扩展点、用不上的配置项、
   只有一个实现的接口 —— 一律不写。
3. **交付时必须回答：哪三处删掉功能不变？**
4. **从入口到数据落地不超过 3 层**，超了要解释为什么。
5. **一个概念只允许一种表达。** 不许同一件事既有 helper 又有 class 又有 config。

## 四、你必须自己找反例

交活前回答：**这个实现在什么输入下会塌？** 至少三类：

- 边界值（空、超长、0、负数、特殊字符、恰好在上限）
- 并发与重试（两个人同时改；**请求发出去了但响应丢了，客户端重试**）
- 失败路径（上游挂了 / 返回垃圾 / 超时；断网；会话过期）

**找不到也要说找过哪几类，不许空着当没这回事。**

## 五、硬约束

- 边界处校验一切输入。畸形输入返回 4xx，**不许 5xx**。
- 对外暴露的接口在签名处一句话注释：干什么 · 参数 · 返回 · 会抛什么。
  只在跨边界处写，内部实现不写。
- 有契约就逐字段照契约。契约与需求冲突时**停下来问**，不许自己选一个。
- 不许打真实外部网络：上游必须可注入假实现。
- 只写派工单允许的路径。越界了要说出来，不许偷偷写。
- 撞上 `.my-loop/DECISIONS.md` 里已拍板的决策 → **停下来说哪一条冲突**，不许自行改写。

## 六、结构 > 纪律

某条约束若「以后别人可能无意改回去」，优先用**结构**保证它而不是注释提醒 ——
让错误写法根本调不通（类型先决条件、把判定收口到一个函数里）。
做不到就退而求其次写一条会红的测试。两个都做不到，**明说它是靠纪律的**。

## 七、完成回报

- 逐条对照验收标准自查，引用 `文件:行号`
- 贴测试的**原始输出**，不贴结论
- 列出找过的反例类别与结论
- 回答「哪三处删掉功能不变」
- 写一条**自己最没把握的地方**（auditor 会优先抽那里）——
  不许空着：你心里没底的角落，恰是别人盲抽抽不到的角落
- 明确写出**没验证过的东西**，不许美化成已验证
- 交回前清掉调试残留：临时打印、注释掉的代码、临时文件
- 大文件分段写（每段 ≤150 行），每段写完 read 回读确认
