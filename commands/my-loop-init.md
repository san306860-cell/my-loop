先加载 `my-loop` skill 读完整手册，然后按手册 **§11** 初始化当前项目。
**初始化单独做完，不掺一行业务代码** —— 手册说的。

只做这些：

1. 用 §11 里那条 `cp -Rn` 装模板（路径以手册为准，别在这里另抄一份）。
2. 把触发块追加进项目根的 `CLAUDE.md`（没有就创建）——
   **这是让新会话不打命令也能走 my-loop 的唯一保证**，不许跳过：

   ```bash
   BLOCK="/Users/a1234/.claude/skills/my-loop/assets/claude-md-block.md"
   if grep -q 'my-loop:trigger' CLAUDE.md 2>/dev/null; then
     echo "已有触发块，跳过"
   else
     if [ -s CLAUDE.md ]; then
       # 原文件可能没有行尾换行，先补上，再空一行 —— 少了会和上一段粘成一段
       [ -n "$(tail -c 1 CLAUDE.md)" ] && printf '\n' >> CLAUDE.md
       printf '\n' >> CLAUDE.md
     fi
     cat "$BLOCK" >> CLAUDE.md && echo "已追加触发块"
   fi
   ```

   已有 `CLAUDE.md` **只追加到末尾，不覆盖、不重排、不改别人写的内容**。
   块的正文在那个文件里，**别在这里或手册里另抄一份**。
3. **把环境真跑通，不许只装文件**：找到（或问我）**启动 / 测试 / 验证**三条命令，
   各真跑一遍、至少跑通一个现成测试；`CLAUDE.md` 里没有这三条命令就补上（已有就核对）。
   空项目没得跑就写「暂无」，**不许装跑过**。git 仓库就打一个初始化检查点。
4. **`ls` + 打开 `CLAUDE.md` 末尾核实真的装上了**，别只看退出码。
   对照手册 §11 的口径自查并回报：**能启动 · 能测试 · 能看进度 · 能接手**。
   顺手报告入口文件行数；已有 `CLAUDE.md` / `AGENTS.md` 超过 200 行的，
   按手册 §10 列出拆分候选段（**只报告不动手**，拆不拆人拍板）。
5. 没有跨竖切共享就删掉 `SHARED.md` —— 手册说的。
6. 问我**一件事**（只这一件）：这个项目里有没有「重犯一次会疼的」坑，
   或者明确不许 agent 碰的东西？
   - 有 → 一条一句话写进 `.my-loop/DECISIONS.md`（定了什么·别做什么·为什么 + 守卫）
   - 没有 → **留空表**。空表比塞满通用条款有用，别自己脑补通用条款填进去
   - 项目已有 `CLAUDE.md` / `AGENTS.md` 的，里面写过的别抄进决策表（一条规矩只写一处）
7. 告诉我：**以后直接说需求就行，不需要打任何命令**，你会自己分级。

除第 2 步触发块和第 3 步三条命令外，
不预铺别的目录、不预铺模板、不建状态机、不写 PRD / 架构 / 代码。
